# DocScan חדש — בנייה עצמאית
אפליקציית Android חדשה מאפס בענף `rebuild/camscanner-reference`, עם Kotlin, Compose, CameraX, Room ו־OpenCV. אין תלות או העתקת קוד, מסננים, משאבים או תשתית מה־DocScan הישן. הפרופיל הרגיל משתמש בעיבוד העצמאי. נוסף פרופיל Native מחקרי שמפעיל את רכיב הסרת הצללים MagicEnhancer מהחבילה שסופקה; אין כאן העברה מלאה של מנוע CamScanner.

[הערות גרסת הניסוי](docs/PREVIEW_0.1.4_HE.md) · [ממצאי Frida והמסננים](docs/RESEARCH_0.1.4_HE.md).

**סטטוס פרסום:** הקוד הועלה וה־APK נבנה ואומת. יצירת Release/תג חדש נחסמה ב־GitHub בשגיאת הרשאה 403; אין עדיין Release 0.1.4 ב־GitHub. קובץ ההתקנה נמסר בשיחה. אין לשנות את main או להרחיב הרשאות אוטומטית לצורך עקיפת החסימה.

ממשק חדש לפי ההדמיה שנבחרה: ספרייה עם בחירה/סל/שחזור, מצלמה ועורך כהים, צילום יחיד/קבוצה, מסננים בפס קבוע ותפריט לשמירת כל העמודים בגלריה. אותו מזהה חבילה וחתימה כמו Native 0.1.3; מתקינים כעדכון ללא הסרת ההתקנה.

גרסת Pre-release, לא סופית. בדיקות build ו־API 29/35 עברו; API 28 נתקל בכשל תשתית ונבדק מחדש. התקבל trace אמיתי של Java ו־JNI בתוך DocScan; PAPER ו־Magic Color עברו בדיקות סינתטיות, ו־No Shadow החזיר ‎-1 גם ללא Frida. שאר המחקר והמגבלות מפורטים בהערות הגרסה. אין כאן כל המסננים של CamScanner או בדיקת טלפון אמיתי.

זו אינה העברה מלאה של כל מסנני CamScanner: הסרת כתב יד וסימני מים משתמשות בשירותי שרת, ולמסלולי ScannerEngine האחרים עדיין חסר אתחול תקין עבור DocScan. המסננים העצמאיים הקיימים אינם מוצגים כמסננים המקוריים האלה. בדיקות Android של הפרופיל הרגיל אינן אימות של פרופיל Native.

ה־APK הוא Debug מחקרי ל־ARM64, Android 8 ומעלה. אותה חתימה ומזהה חבילה כמו Native 0.1.1, ולכן מיועד לעדכון שלה ללא הסרת ההתקנה. שני הפרופילים עברו 9 מבחני יחידה, Lint ובניית APK; [בדיקות Android הנוכחיות](https://github.com/4pdara/DocScan/actions/runs/42133225484) מפורטות בדוח המסננים. אין כאן אימות איכות בטלפון או הרצת Frida שהצליחה.

## ניסוי Native 0.1.1 — ההורדה הקודמת
[הורדת APK Native](https://chatgpt.com/library?file_id=libfile_47331e9ace8c8191855a422bb07736b6&account_id=e5ab30f5-f7c8-4dad-b0d8-9fb6a7126f95) · [סכום ביקורת](https://chatgpt.com/library?file_id=libfile_4eef57c8f25c8191941e56b973e40c28&account_id=e5ab30f5-f7c8-4dad-b0d8-9fb6a7126f95) · [ממצאים, בדיקות ומגבלות](docs/JNI_ENGINE_RESEARCH_HE.md).

התקינו בשם ״DocScan ניסוי Native״ לצד היישומים הקיימים. לאחר צילום/ייבוא פתחו עריכה ובחרו **CamScanner** בפס המסננים. רק מסנן זה מפעיל את הרכיב המקורי; שאר המסננים והזיהוי נשארו מהמימוש העצמאי החדש.

ה־APK נבנה, עבר 5 מבחני יחידה ו־Lint, וספריותיו וחתימתו אומתו. הרכיב עיבד תמונות סינתטיות 96×128 ו־768×1024 באמולציית ARM64 דרך JNI. האפליקציה המלאה עם הרכיב **טרם נבדקה ב־Android פעיל או בטלפון**; בדיקת Frida של CamScanner עצמה לא הושלמה בגלל סביבת ההרצה הלא יציבה. זו גרסת Debug מחקרית, לא Release לחנות.

לבניית הפרופיל הנוכחי נדרשת תיקייה פרטית עם שש הספריות המדויקות בתת־תיקייה `arm64-v8a`: חמש הספריות שבדוח המקורי ו־libimageprocessor.so שמפורט בדוח המסננים. הן אינן ב־Git:
```sh
./gradlew -PcamScannerNativeDir=/absolute/private/directory testDebugUnitTest lintDebug assembleDebug
```

## בנייה
נדרשים JDK 17, Android SDK Platform 36 ו־Build Tools 35.0.0. הגדירו `ANDROID_HOME` או `sdk.dir` בקובץ מקומי.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest
```

APK מקומי: `app/build/outputs/apk/debug/app-debug.apk`.

[הורדת גרסת הניסוי — ZIP עם APK ו־SHA256](https://github.com/4pdara/DocScan/actions/runs/42046313604/artifacts/13425686107). חלצו את `DocScan-New-0.1.0.apk` והתקינו לצד היישום הקיים. התוצר זמין עד 5 בדצמבר 2026 ודורש גישה לריפו הפרטי.

[ריצת האימות שעברה](https://github.com/4pdara/DocScan/actions/runs/42046313604), בקוד `2244aa1`: 5 מבחני יחידה; Lint ללא שגיאות (19 אזהרות); 6 בדיקות Android בכל אחד משני אמולטורים — Android 10 באנגלית ו־Android 15 בעברית. נבדקו גם צילום מהמצלמה המדומה, שמירת מקור, PDF, עיבוד מלא וממשק. צילומי המסך והגבולות המדויקים של הבדיקות מפורטים בדוח. בדיקות טלפון אמיתי ואיכות צילום השוואתית טרם בוצעו.

## נתונים וגבולות
העבודה מקומית; אין חשבון או הרשאת אינטרנט. נדרשת מצלמה רק לצילום. ייבוא וייצוא משתמשים בבורר הקבצים של Android.
המקורות נשמרים באחסון הפרטי של האפליקציה. הסרת **האפליקציה החדשה** מוחקת אותם. שמרו מקורות ו־PDF ליעד חיצוני לפני הסרה; PDF אינו גיבוי שניתן לשחזר ממנו את כל העריכות.

אין עדיין גיבוי/שחזור מלא, ייבוא PDF, הדפסה, OCR, יישור קימור ספר, פיצול שני עמודים או הסרת עצמים. אין הקטנה שקטה בעת כשל זיכרון. חתימה קבועה, בדיקות מצלמה פיזית ויכולות ההמשך מפורטות בדוח.
