# DocScan

אפליקציית Android לסריקת מסמכים, עם ממשק עברי ו־RTL ועבודה מקומית במכשיר.

## גרסת הפיתוח 0.3.0

גרסה 0.3.0 משפרת את זיהוי המסגרת בעזרת קצוות הדף, מקצרת את חלון היציבות מ־900 לכ־450 מילישניות וסובלת רעידות קטנות ואיבוד קצר של הזיהוי. אלה הגדרות המנגנון; אין התחייבות לזמן צילום כולל במכשיר. במצלמה מופיע פס תמונות של העמודים שנשמרו, ואפשר לפתוח עמוד, לתקן אותו ולחזור לסריקה. צילום ידני, השהיה והמשך נשארים זמינים.

לתיקון החיתוך: פותחים מסמך, בוחרים **עריכה ← חיתוך ויישור**, גוררים את הפינות ולוחצים **החל חיתוך**. בעורך נוספו **ניקוי רקע** ו־**טקסט משופר** עם עוצמה נשלטת, וכן **צילום מחדש** לעמוד בודד. צילום מחדש מחליף את המקור רק לאחר שהצילום החדש נשמר; ביטול או כשל משאירים את העמוד הקודם. החיתוך, הסיבוב, המסנן ועוצמתו נשמרים בנפרד מהמקור ומשמשים גם בייצוא.

במסך המסמך אפשר לבחור **שמירת PDF**, **שמירת JPEG** או שיתוף PDF. שמירת JPEG פותחת בחירת תיקייה ומייצאת קובץ נפרד לכל עמוד לפי הסדר. היא אינה כתיבה אוטומטית לגלריה. הזיהוי עדיין דורש גבולות גלויים וניגוד מספיק; בבדיקות נוספו גם דף ורקע בהירים ודף כהה. סריקה של שני דפים במקביל, הסרת קמטים וכיתוב מהצד השני, ייבוא PDF ושמירה ישירה לגלריה עדיין אינם ממומשים. איכות במצלמה פיזית דורשת בדיקה נוספת.

## בנייה מקומית

נדרשים JDK 17 ו־Android SDK עם Platform 36 ו־Build Tools 35.0.0. פותחים את הפרויקט ב־Android Studio או מגדירים את נתיב ה־SDK בקובץ `local.properties` מקומי שאינו נכנס למאגר.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

ב־Windows משתמשים ב־`gradlew.bat`. קובץ ההתקנה נוצר ב־`app/build/outputs/apk/debug/app-debug.apk`. לבדיקת הייצוא על מכשיר או אמולטור מחובר:

```sh
./gradlew connectedDebugAndroidTest
```

## בנייה ב־GitHub

ה־workflow שבמאגר מריץ בדיקות יחידה, Lint ובניית APK בכל push ל־`main` וב־pull requests. משימה נוספת בודקת באמולטור Android 10 את ייצוא ה־PDF, החיתוך, שמירת המקורות וכפתורי הסריקה, ושומרת צילומי מסך. ה־APK והדוחות זמינים כ־Artifacts בהרצת Actions למשך 14 ימים. תהליך הפרסום הידני מקבל מספר ריצת בנייה מוצלחת ומפרסם את ה־APK שנבדק, לפי הגרסה והערות ההפצה שבאותו commit.

## פרטיות וגרסאות

סריקה, עיבוד וייצוא מבוצעים מקומית. אין שרת, חשבון, מודעות או הרשאת אינטרנט. נדרשת הרשאת מצלמה לצילום; בחירת תמונות ושמירת PDF מתבצעות דרך ממשק המערכת. גיבוי הענן והעברה אוטומטית של נתוני האפליקציה הוחרגו בהגדרות הגיבוי. מחיקת האפליקציה מסירה טיוטות ומקורות פרטיים; קובצי PDF שיוצאו בנפרד נשארים במקומם.

APK מסוג Debug מיועד להתנסות, בשם חבילה נפרד שמסתיים ב־`.debug`. הוא אינו גרסת חנות. חתימת הפצה קבועה וגיבוי מפתח חתימה יוסדרו לפני הפצה יציבה; בניות Debug ממקורות שונים עשויות לדרוש הסרת גרסת הניסוי הקודמת.

שם המוצר הוא **DocScan**. דוגמאות הלוגו יוכנו בשלב נפרד.
