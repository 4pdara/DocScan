# DocScan — התחלה חדשה

ענף עצמאי: `rebuild/camscanner-reference`.

האפליקציה החדשה תיכתב מאפס; בראש הענף אין קוד אפליקציה או תשתיות בנייה מה־DocScan הישן. היסטוריית Git נשמרה לצורך עקיבות בלבד.

בשלב הנוכחי נשמרו מחקר ותכנון. אין עדיין אפליקציה חדשה פעילה, APK חדש או אימות איכות מצלמה.

[התכנון והיקף הבנייה מחדש](docs/REBUILD_CAMSCANNER_REFERENCE_HE.md).

ממצאי חבילת CamScanner אינם קוד מקור מלא בר־בנייה; יש להבחין בין שחזור חלקי, ניתוח בינרי ומימוש עצמאי. קובצי ההפניה והקוד המפורק נשארים מחוץ לריפו.
