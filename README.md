# DocScan

אפליקציית אנדרואיד מתוכננת לסריקה מהירה של מסמכים, עם צילום רציף אוטומטי, חיתוך ותיקון, ייבוא תמונות ו־PDF, וייצוא ל־PDF אחד או לתמונות בגלריה.

## תיעוד

- [המחקר, האפיון ותוכנית הפיתוח](docs/PRODUCT_SPEC_HE.md)

## כיוון הפיתוח

ההמלצה ההנדסית היא Kotlin, Jetpack Compose ו־CameraX, עם רכיבי עיבוד נבחרים לאחר בדיקת רישוי. הבחירה הסופית במנוע הסריקה תתבסס על ניסוי במכשיר אמיתי: צילום 30 דפים בלי לחיצה בין דפים, מניעת כפילויות, שמירת מקור וייצוא תקין.

הגרסה הראשונה מיועדת לעבוד מקומית, עם ממשק עברי ו־RTL ואפשרות לאנגלית. OCR, סנכרון ויכולות AI מתקדמות מתוכננים להיבחן בנפרד.

## מצב המימוש

המאגר כולל בשלב זה תיעוד תכנון בלבד. אין עדיין קוד אפליקציה, APK או תוצאות build ובדיקות מצלמה. שלב הפיתוח הראשון הוא ניסוי מנוע הסריקה והקמת מסלול בנייה ובדיקות.

## עבודה עם GitHub

כל אבן דרך תכלול בדיקת המאגר והוראותיו, מימוש תחום, בדיקות רלוונטיות, עדכון תיעוד, סקירת השינויים ו־commit. עדכונים יידחפו למאגר ותוצאות CI ייבדקו כשהתשתית תוקם. מפתחות חתימה וסודות לא ייכנסו למאגר.

## מיתוג

שם המוצר הוא **DocScan**. דוגמאות הלוגו יוכנו בשלב נפרד.
