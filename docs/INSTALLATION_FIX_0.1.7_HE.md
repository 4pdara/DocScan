# DocScan 0.1.7.1 — חבילת התקנה רחבה ומתוקנת

**[הורדת APK מתוקן](https://github.com/4pdara/DocScan/releases/download/native-v0.1.7-preview/DocScan-0.1.7-universal.apk)** · [SHA256](https://github.com/4pdara/DocScan/releases/download/native-v0.1.7-preview/SHA256SUMS.txt).

לאחר דיווח שהחבילה לא תקפה בטלפון Samsung, נמצאה מגבלת התקנה בחבילה הקודמת: היא כללה ARM64 בלבד. שם יצרן אינו מספיק כדי לקבוע מה גרם לדחייה בטלפון המסוים; לא נאסף ממנו קוד שגיאה של מנהל החבילות. גרסת התיקון מיועדת למעבדי ARM ו־Intel ב־32 וב־64 ביט, ב־Android 8 ומעלה. אין הבטחה לתמיכה בכל טלפון ישן או בכל מכשיר פיזי.

## מה השתנה

- APK יחיד עם `armeabi-v7a`, ‏`arm64-v8a`, ‏`x86`, ‏`x86_64`, ואריזת ספריות דחוסה שנחלצת בהתקנה.
- אותה חבילה `com.docscan.rebuild.csnative`, אותו מפתח חתימה ותעודת SHA256 `69dce468c27a15728cf501feb9bf76d67263031f5ee34604f78b6be55465e89c`. ‏versionCode 8 ו־versionName `0.1.7.1-universal-preview` מאפשרים עדכון של 0.1.5 ושל 0.1.7 בלי להסיר התקנה.
- עיצוב 0.1.6, שמירת המקורות בנפרד וייצוא ברזולוציה המקורית נשמרו. אין שינוי בסכמת Room או בקוד האחסון.
- במכשיר שבו כל רכיבי ARM64 נטענים כראוי זמינות 14 בחירות העיבוד של Native, כולל תיקון Pro. כשמנוע זה לא זמין, האפליקציה מציגה שבע בחירות מקומיות פעילות וחיווי ״עיבוד מקומי פעיל במכשיר זה״. מסנני Native שאינם זמינים אינם מוצגים כאפשרויות פעילות. מתכון Native שמור אינו מוחלף בשקט במסנן אחר; אפשר לבחור מסנן מקומי בלי לשנות את המקור.
- אין להסיר את ההתקנה הקיימת. הסרה מוחקת את הנתונים הפרטיים שלה. הקובץ הישן שהיה ARM64 בלבד מוסר מה־Release רק לאחר אימות החבילה החלופית.

## אימות חבילת המסירה

תהליך הפרסום בודק את קובץ ה־APK החתום המדויק המיועד להורדה, ולא מסתפק בקובץ CI בעל חתימה אחרת. האפליקציה וחבילת בדיקות ההתקנה חתומות באותו מפתח פרטי שנשאר מחוץ למאגר. המניפסט שנשמר במאגר מכיל מטא־נתוני ZIP ורשומות חתימה ציבוריות בלבד; אין בו קוד APK, ספריות יצרן או מפתח חתימה.

לפני שהפרסום מותר, הבדיקות הבאות חייבות להסתיים בהצלחה:

| סביבה | הבדיקה הנדרשת |
| --- | --- |
| Android 8, ‏x86 ב־32 ביט | דחייה צפויה של חבילת ARM64 הישנה, התקנה של החבילה האוניברסלית ו־12 בדיקות אחסון, עיבוד מקומי, עריכה וייצוא |
| Android 11, ‏x86_64 | התקנת ה־APK הישן שפורסם, עדכון לקובץ החתום החדש בלי הסרה, שימור קובץ מקור מדומה ו־23 בדיקות אפליקציה |
| Android 16 בעברית, ‏x86_64 | התקנה נקייה ו־23 בדיקות אפליקציה |
| Android 15 בעברית, עמודי זיכרון 16 KB | התקנה ו־12 בדיקות אחסון, עיבוד, עריכה וייצוא; אימות שבפועל נבדק גודל עמוד 16,384 בתים |
| פרופיל ARM64 הייעודי | בדיקות Native בתוך אמולטורים עם תרגום ARM64, כולל Pro, כל המסננים ושימור מקורות |

בדיקות המיועדות למנוע Native מדולגות במפורש כשמנוע זה אינו זמין במכשיר הבדיקה. שאר בדיקות האפליקציה חייבות לעבור. קישורי הריצות, מספר הגרסה, חתימת האפליקציה, המעבדים ו־SHA256 נמצאים ב־BUILD.json המצורף. בדיקות אמולטור אינן בדיקה בטלפון Samsung פיזי ואינן הוכחת איכות זהה ל־CamScanner. בדיקת טלפון אמיתי עדיין נדרשת.

[תיעוד Android על גדלי עמודי זיכרון](https://developer.android.com/guide/practices/page-sizes) מסביר את ההבדל בין יישור ZIP, יישור ELF ותאימות בזמן ריצה; אין להסיק מבדיקת ZIP בלבד שהאפליקציה תעבוד בכל מכשיר.
