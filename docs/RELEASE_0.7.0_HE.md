# DocScan 0.7.0 — גיבוי ושחזור

- בספרייה: **אפשרויות נוספות ← גיבוי כל המסמכים**, ובחירת מקום לשמירת ZIP.
- נשמרים המקורות, סדר העמודים, חיתוך, מסננים וכל התאמות התמונה, ללא קידוד מחדש של המקורות.
- **שחזור מגיבוי** בודק תקינות ומוסיף עותקים חדשים. הקיימים נשמרים; שחזור חוזר מוסיף עותקים נוספים.
- הסברים בעברית ובאנגלית, חיווי וביטול לפני שלב השמירה הסופי.

הגיבוי אינו מוצפן ואינו אוטומטי. יש לבחור יעד מחוץ לאחסון הפרטי של האפליקציה. הגבול הוא 2 GiB מקורות, 1,000 מסמכים ו־10,000 עמודים; נחוץ גם מקום זמני. [פירוט המימוש והבדיקות](https://github.com/4pdara/DocScan/blob/main/docs/MILESTONE_7_HE.md).

זהו APK מסוג Debug להתנסות. חתימה שונה עשויה לחייב הסרת התקנה קודמת. לפני הסרה יש לייצא מסמכים חשובים; בגרסאות שלפני 0.7 אין גיבוי מלא. PDF/JPEG אינם תחליף לארכיון המקורות והעריכות.

איכות הסריקה לא השתנתה בגרסה זו. ספר כפול, קימורים, תעודה דו־צדדית ו־OCR טרם מומשו. [תוכנית שיפור האיכות](https://github.com/4pdara/DocScan/blob/main/docs/SCAN_QUALITY_PLAN_HE.md) מתארת ניסוי עתידי, ולא תכונות שכבר נוספו.
