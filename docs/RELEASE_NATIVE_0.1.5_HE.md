# DocScan Native 0.1.5 — גרסת ניסוי

עדכון 12 בנובמבר 2026: [Native 0.1.7](PREVIEW_0.1.7_HE.md) משלב את יכולות 0.1.5 עם עיצוב 0.1.6 ותיקוני Pro, באותו מזהה חבילה ובאותה חתימה. המסמך להלן מתעד את הגרסה ההיסטורית.

- ממשיכה את העיצוב של אפשרות 5, עם 14 בחירות עיבוד כולל מקור.
- נוספו הבהרה וחיסכון בדיו במימוש עצמאי, לוח, לוח לנייר ולוח הפוך.
- תוקן הכשל הממוקד של הסרת צללים בסיווג 4, בלי החלפה שקטה למסנן אחר.
- המקורות נשמרים ללא שינוי; עריכות נשמרות בנפרד, ללא מיגרציה חדשה למסד הנתונים.

בדיקות האפליקציה: https://github.com/4pdara/DocScan/actions/runs/42189237344
בדיקות Native ו־Frida: https://github.com/4pdara/DocScan/actions/runs/42189237349

עברו 9 מבחני יחידה, Lint ללא שגיאות ו־16 בדיקות רגילות בכל אחד משלושה אמולטורים. בכל אחת משתי סביבות Native עברו 67 מקרי אימות, כולל שתי דחיות צפויות. תועדו שמונת מסלולי Native בתוך DocScan.

לא התקבל trace מתוך CamScanner המקורית. כל מסנני השירות בענן אינם כלולים. אין בדיקת טלפון אמיתי או מדידת איכות מול CamScanner.

ה־APK הוא Debug ניסיוני, Android 8 ומעלה ו־ARM64 בלבד. החבילה com.docscan.rebuild.csnative, גרסה 5. אותה חתימה כמו Native 0.1.1/0.1.3/0.1.4; מיועד להתקנה כעדכון ללא הסרת הגרסה הקיימת. זו אינה חתימת חנות קבועה.
