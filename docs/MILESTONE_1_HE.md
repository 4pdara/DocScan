# DocScan המימוש הראשון

## היקף

זהו בסיס Android להתנסות, ולא השלמת כל דרישות האפיון. נבחר מסלול CameraX לניסוי ראשון; אמינות זיהוי וצילום רציף ואיכות העיבוד המקצועי עדיין דורשות ניסויים נפרדים.

| תחום | מה ממומש |
| --- | --- |
| תשתית | Kotlin, Compose, CameraX, Room, Gradle Wrapper ובניית GitHub Actions |
| ממשק | מסמכים, מצלמה, עמודים ועורך; עברית ו־RTL, אנגלית ומצב כהה |
| צילום | צילום ידני באיכות המצלמה, הוספת כמה עמודים למסמך ופנס |
| ייבוא | תמונות שנבחרו בבוחר המערכת; מקור עד 50 MiB ועד 100 מיליון פיקסלים |
| אחסון | מקור בלתי משתנה, פרמטרי סיבוב ומסנן, שמירת כל עמוד לאחר השלמת הכתיבה ושחזור טיוטה |
| עריכה | סיבוב, מקור, צבע משופר, גווני אפור ושחור־לבן; השוואה למקור |
| עמודים | שינוי סדר ומחיקה לאחר אישור |
| PDF | מסמך אחד מכל העמודים, סיבוב ומסנן לפי המצב השמור, A4 לאורך או לרוחב ושיתוף דרך Android |
| פרטיות | אין הרשאת אינטרנט; קבצים פנימיים פרטיים; החרגה מגיבוי ומהעברת נתונים אוטומטית |

## מגבלות ושלבים הבאים

צילום אוטומטי רציף, זיהוי קצוות, חיתוך ותיקון פרספקטיבה עדיין אינם ממומשים. המסננים הנוכחיים בסיסיים ואינם מנוע לניקוי קמטים, צללים או כיתוב מצדו השני של הדף. אין ייבוא PDF, ייצוא תמונות לגלריה, OCR או סנכרון. אין בשלב זה בדיקת מצלמה במכשיר פיזי או מדידת ביצועים במסמך בן 100 עמודים. העיצוב הוא כיוון ראשוני; חלופות העיצוב והלוגו עדיין לבחירה.

ייצוא PDF מייצר מסמך של תמונות, ללא שכבת טקסט שניתן לחפש בה. שמירת קובץ דרך ספק חיצוני תלויה במערכת ובספק שנבחר. במצב כשל ייתכן שספק השמירה יותיר קובץ ריק או חלקי; המקורות והטיוטה נשמרים ומוצגת שגיאה.

## בדיקות אוטומטיות

11 בדיקות יחידה מכסות שימור פיקסלים וערוצי צבע, שמות קובצי ייצוא, שימור מקור ועריכות לאחר פתיחה מחדש, קלט פגום, סדר ומחיקת עמודים והתאוששות מכתיבה שלא הושלמה. בדיקות התמונה משתמשות בגרפיקה Native של Robolectric במקום במפענח תמונות מדומה.

בדיקת Android נפרדת מייבאת שני עמודים, מסובבת אחד, מפעילה מסנן, מייצאת PDF, פותחת אותו ב־PdfRenderer ומוודאת שני עמודים בכיוונים הצפויים ושימור של קובצי המקור. היא מיועדת להרצה במכשיר או באמולטור. מצב הריצות בפועל מופיע בדוחות המקומיים וב־GitHub Actions; עצם קיום הבדיקה אינו הוכחה שעברה במכשיר פיזי.

פקודת הבדיקה המקומית:

```sh
./gradlew cleanTestDebugUnitTest testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

## בדיקת התנסות בטלפון

1. להתקין את APK הפיתוח ולבדוק שמסך המסמכים ברור וקריא.
2. לפתוח סריקה, לאשר הרשאת מצלמה ולצלם 3–5 דפים בלחיצה לכל דף. לוודא שהמונה מתעדכן לאחר השמירה.
3. לסיים, לפתוח עמוד, לסובב ולבחור מסנן; להשוות למקור ולבדוק שהמקור נשאר זמין.
4. לשנות סדר עמודים, לשנות את שם המסמך, לסגור את האפליקציה ולפתוח מחדש.
5. לייבא כמה תמונות באמצעות בוחר המערכת ולבדוק שהעמודים זמינים לעריכה.
6. לשמור PDF, לפתוח אותו באפליקציית PDF אחרת ולבדוק סדר, כיוון, מסנן וקריאות.
7. לשתף PDF דרך תפריט Android ולוודא שהקובץ יוצא רק לאחר פעולת השיתוף של המשתמש.
8. לבדוק דחיית הרשאת מצלמה וחזרה מהגדרות ההרשאות, וכן ממשק עברי, אנגלי, גופן מוגדל ומצב כהה.
9. לבדוק שמחיקה מחייבת אישור ושקובץ שיוצא בנפרד אינו נמחק יחד עם הטיוטה.

## אבן הדרך הבאה

ניסוי בזיהוי קצוות וצילום רציף עם מניעת כפילויות, לצד חיתוך ותיקון פרספקטיבה. במקביל נבחן דוגמאות של קמטים קלים וכיתוב מהצד השני של הדף כדי לבחור צינור עיבוד שניתן למדוד ולשלב בעורך בלי לפגוע במהירות ובמקור.
