# DocScan 0.3.0: כלים חדשים

**קובץ להורדה:** `DocScan-0.3.0.apk` (מצורף ל־Release).

**התקנה:** ישר מעל 0.2.1 ומעלה. אין צורך להסיר את הגרסה הקודמת, והמסמכים נשארים.

הגרסה כוללת את כל התיקונים של 0.2.3 (החיתוך לפי המסגרת שבמצלמה, וזיהוי ספר פתוח), ומוסיפה את החלק הראשון של קבוצה א'. כל הכלים עובדים בלי אינטרנט. לא נוספה שום ספרייה חיצונית.

## איפה נמצאים הכלים
- **מסך "כלים":** מחולק לפי הנושאים של CamScanner: סריקה, ייבוא, המרה, עריכה, כלי עזר. בכלי שעובד על מסמך קיים, בוחרים קודם את המסמך.
- **בתוך מסמך:** "⋮" ← "כלים".

## הכלים
| כלי | מה הוא עושה |
| --- | --- |
| הדפסה | שולח את המסמך לשירות ההדפסה של Android. אפשר להדפיס במדפסת או לבחור "שמירה כ־PDF". |
| ל־Word | שומר קובץ ‎.docx עם הטקסט המזוהה: עמוד Word לכל עמוד סרוק, ופסקאות מימין לשמאל בעברית. עמוד שעוד לא זוהה בו טקסט, הטקסט שלו מזוהה עכשיו, במכשיר. |
| לתמונות | שומר את כל העמודים בגלריה (כמו "שמירת תמונות לגלריה"). |
| תמונה ארוכה | כל העמודים בתמונת JPEG אחת, זה מתחת לזה. רוחב התמונה עד 2000 פיקסלים, וגודלה הכולל עד 16 מיליון פיקסלים. |
| סימן מים | טקסט לבחירתכם על כל עמודי המסמך, בתצוגה ובכל ייצוא. המיקום לבחירה: באלכסון, לרוחב במרכז, למעלה, למטה או לאורך הצד. כדי להסיר אותו משאירים את השדה ריק. |
| חותמת זמן | התאריך והשעה בפינה שבחרתם בהגדרות. לחיצה נוספת מסירה אותה. |
| חילוץ עמודים | בוחרים עמודים ושומרים רק אותם כ־PDF. |
| גודל ה־PDF (דחיסה) | בכל שמירת PDF בוחרים: איכות מקורית, מאוזן (עמודים עד 2000 פיקסלים) או קטן (עד 1200 פיקסלים). |
| ייבוא PDF | כל עמוד ב־PDF הופך לעמוד במסמך, ברזולוציה של 200 DPI. ה־PDF עצמו לא משתנה. |

**לא מתווספים לבד:** סימן המים וחותמת הזמן כבויים כברירת מחדל. במסך "אני" ← "סימן מים וחותמת זמן" אפשר להפעיל אותם לכל סריקה וייבוא חדשים, ולבחור את הטקסט ואת המיקום. עמודים שכבר נשמרו לא משתנים. כדי להוסיף אותם למסמך קיים, משתמשים בכלים של המסמך.

סימן המים וחותמת הזמן נשמרים כחלק מהעריכה של העמוד, ולכן נכללים גם בגיבוי. צילום המקור לא משתנה. אחרי הוספה או הסרה שלהם, צריך לזהות מחדש את הטקסט של העמוד.

## עוד לא בגרסה הזו
בגרסה הבאה של קבוצה א':
- סריקת QR;
- תעודה מזהה (שני צדדים בעמוד אחד);
- חתימה;
- PDF עם סיסמה. הכלי הזה דורש ספרייה חיצונית, ואבדוק קודם את הרישיון שלה.

אחרי קבוצה א' עוברים לקבוצה ב': יישור אוטומטי של דף מעוקל, לפי הצילום ששלחת והתוצאה של CamScanner.

## אימות
- **בדיקת מכשיר חדשה:**
  - סימן המים וחותמת הזמן נשמרים בעריכה ומשנים את העמוד שמוצג.
  - שלושת גדלי ה־PDF, ו־PDF "קטן" יוצא קטן מהמקורי.
  - חילוץ עמוד אחד.
  - תמונה ארוכה.
  - קובץ Word תקין, כולל עברית מימין לשמאל ותווים מיוחדים.
  - ייבוא של PDF בן שני עמודים.
- **היקף הבדיקות:**
  - Android 11, Android 15 בעברית ו־Android 15 עם ספריות ARM64: 36 בדיקות;
  - Android 8 ואמולטור 16 KB: 23 בדיקות.
- הדפסה בפועל לא נבדקה באמולטור. נבדקו רק יצירת ה־PDF ומסירתו לשירות ההדפסה.
