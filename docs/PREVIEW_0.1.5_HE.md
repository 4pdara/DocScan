# Native 0.1.5 — הרחבת מסננים ותיקון No Shadow

גרסת ניסוי בענף `rebuild/camscanner-reference`; ממשיכה את עיצוב אפשרות 5 של 0.1.4. אין שינוי ל־main או לנתוני התקנה קיימת. אין קוד מענפי DocScan הישנים.

## מה השתנה

- נוספו הבהרה וחיסכון בדיו במימוש עצמאי, עם שמירת פרטי כתב, צבע במסנן ההבהרה ורזולוציית הפלט.
- נוספו לוח, לוח לנייר ולוח הפוך, באמצעות מסלולי ImageProcessor שנמצאו בחבילת ההפניה. משטחי הרקע נוצרו ב־DocScan; לוח לנייר כולל הכנת מסכת כתב עצמאית לפני הקריאה ל־Native.
- תוקן מסלול No Shadow לתמונות שסיווג אוטומטי 4 גרם לדחייתן: ניסיון בדוק נוסף באותה פונקציית Native עם סוג 2. שגיאות אחרות עדיין מדווחות, בלי החלפה שקטה ל־PAPER.
- PAPER המוצלח, המקורות, המתכונים הקודמים ועיצוב אפשרות 5 נשמרו. למזהי המסננים החדשים נוספו מתכונים נפרדים; אין שינוי סכמת מסד נתונים.

## מקור המימוש של הבחירות

| בחירה | מה פועל ב־0.1.5 |
| --- | --- |
| מקור | תמונה ללא מסנן, עם העריכות שנבחרו |
| צבע, אפור ושחור־לבן | המימושים העצמאיים הקיימים |
| הבהרה וחיסכון בדיו | מימושים עצמאיים חדשים; אינם מצבי ScannerEngine המקוריים 15/16 |
| CamScanner / PAPER | המסלול הקיים deshadowBitmapNew, מצב 1 |
| Magic Color | deshadowBitmapNew, מצב 3 |
| ללא צללים | deshadowBitmap, אוטומטי 1; ניסיון סוג 2 בכשל המוגדר לעיל |
| היפוך צבעים | ReflectBinaryColorShiftBitmap, מצב 1 |
| Pro מקומי | ImageSilverBulletBitmap, פרמטרים 1,1,1 |
| לוח | ReflectBinaryColorShiftBitmapBG, מצב 2, משטח של DocScan |
| לוח לנייר | מסכת כתב עצמאית + BG מצב 3, משטח לבן של DocScan |
| לוח הפוך | היפוך 1 ולאחריו BG מצב 2 |

יש **14 בחירות בפרופיל Native**, כולל מקור. הסרת כתב יד, הסרת סימני מים והרחבות Pro התלויות בענן אינן מוצגות כאילו נכללו במנוע המקומי. אין מפתח SDK מורשה עבור DocScan למסלולי ScannerEngine האחרים; לא שונו אימותי רישוי ולא הועתקו נתוני הפעלה.

## בדיקות ומחקר

[הדוח המפורט](FILTER_RESEARCH_0.1.5_HE.md) מפריד בדיקה סטטית, Android, Frida ואפליקציית CamScanner המקורית. הוא מתעד גם ניסיונות שלא הצליחו. תוצאות הבדיקה הסופית, SHA256 והורדה יעודכנו לאחר השלמת הסבב האחרון. אין עדיין בדיקה בטלפון אמיתי או מדידת איכות השוואתית מול CamScanner.

## התקנה ונתונים

`com.docscan.rebuild.csnative`, ‏versionCode 5, ‏Android 8 ומעלה, ARM64. אותה חתימת Debug של Native 0.1.1/0.1.3/0.1.4; מיועד להתקנה כעדכון. אין צורך להסיר התקנה קיימת. המקורות נשמרים ללא שינוי ועריכות נשמרות בנפרד. Debug אינו חתימת הפצה קבועה לחנות.

יצירת Release חדש ב־GitHub נחסמה קודם בהרשאת 403. העלאת קוד לענף ויצירת APK אינן הוכחה שפורסם Release חדש.
