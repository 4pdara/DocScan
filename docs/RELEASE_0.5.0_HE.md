# DocScan 0.5.0 — גלריה, איחוד PDF ושיתוף

- שמירה יזומה של תמונות לגלריה, בנוסף לייצוא JPEG לתיקייה ו־PDF.
- שיתוף PDF, תמונות או שניהם, והדפסה דרך Android.
- ייבוא PDF קיים וצירופו לסריקות; איחוד מסמכים עם בחירת סדר ושמירת המקורות.
- ספרייה עם תמונות שער, חיפוש, מיון ותצוגת רשת/רשימה.
- בחירת עמודים לייצוא ולעריכה בקבוצה; מעבר בין עמודים והחלת מסנן לכל המסמך.
- צילום מהיר כברירת מחדל ואיכות גבוהה כאפשרות נפרדת; מצב ידני/אוטומטי נשמר.

PDF מוגבל ל־50 MiB ו־200 עמודים לקובץ ללא סיסמה. עמודי PDF שלא עברו עיבוד תמונה שומרים טקסט וגרפיקה. עיבוד תמונה משטח את העמוד. אין עדיין OCR או יישור קימורי ספר, הסרת עצמים או סנכרון ענן. איכות ומהירות צילום דורשות בדיקה בטלפון פיזי.

זו גרסת ניסוי Debug. מפתח חתימה קבוע עדיין אינו חלק מהפצה יציבה; אם Android דורש הסרת גרסה קודמת, יש לייצא קודם טיוטות חשובות.
