# DocScan v0.2.0 — סריקה רציפה וחיתוך

גרסת ניסוי לאנדרואיד 8.0 ומעלה.

## מה חדש

- **סריקה רציפה מהירה:** זיהוי דף, צילום לאחר התייצבות, המתנה להחלפת דף, השהיה והמשך. אפשר לעבור לצילום ידני.
- **חיתוך אוטומטי ותיקון פרספקטיבה**, גם בתמונות מיובאות.
- **עורך חיתוך:** פתיחת מסמך ← עריכה ← חיתוך ויישור. גרירת ארבע פינות, זיהוי חוזר וחזרה לכל התמונה.
- החיתוך נשמר בטיוטה וב־PDF; הצילום המקורי נשאר ללא שינוי.
- שדרוג נתוני הטיוטות מגרסה 0.1.0, עברית ו־RTL ואנגלית. העבודה מקומית וללא הרשאת אינטרנט.

## איך מתחילים

להוריד את **DocScan-0.2.0-debug.apk** ולהתקין. בסריקה חדשה המתג **סריקה רציפה מהירה** פעיל. מניחים דף בהיר על משטח מנוגד, ממתינים לחיווי השמירה ומחליפים דף. אם הדפים דומים והצילום הבא אינו מתחיל, מוציאים את הדף מהמסגרת לכחצי שנייה.

## מגבלות

זו גרסת **Debug להתנסות**, וטרם אומתה סריקה של ערמת דפים במכשיר פיזי. הזיהוי הראשוני דורש גבולות גלויים ורקע מנוגד. מסנני ניקוי מקצועיים לקמטים, צללים וכיתוב מהצד השני, ייבוא PDF ושמירה לגלריה עדיין בפיתוח.

**חתימות Debug עשויות להשתנות.** אם ההתקנה מעל גרסה קודמת נכשלת בגלל חתימה שונה, יש לייצא קודם מסמכים חשובים ל־PDF. הסרת האפליקציה מוחקת את הטיוטות והמקורות הפרטיים. אין להסיר לפני ייצוא.

ה־APK נלקח מריצת הבנייה והבדיקות המוצלחת המקושרת בהמשך. מצורף SHA256SUMS.txt לאימות ההורדה.
