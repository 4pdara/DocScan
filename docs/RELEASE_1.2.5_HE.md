# DocScan 1.2.5: "צבע קסם" שומר על כריכה כהה, והמסגרת מופיעה מהר יותר

**קובץ להורדה:** `DocScan-1.2.5.apk` (מצורף ל־Release).

**התקנה:** מתוך האפליקציה ("הגדרות" ← "עדכון האפליקציה"), או ישירות מהקובץ. המסמכים נשארים.

## מה תוקן
**1. "צבע קסם" על כריכה כהה.**
- **מה קרה:** כריכת העור הסגולה יצאה כמעט לבנה, עם כתמים ורודים. המסנן בנוי להלבין נייר, ובכריכה הוא הלבין את העור עצמו.
- **מה תוקן:** המסנן מזהה עכשיו מסמך כהה, ושם הוא שומר את הצבעים: הכריכה נשארת כהה, אותיות הזהב בולטות, והכול חד יותר, כמו ב־CamScanner.
- **"Magic Pro":** תוקן באותה דרך.
- **דפי נייר:** יוצאים בדיוק כמו קודם.

**2. המסגרת במצלמה.**
- **מה קרה:** בסרטון ששלחת המסגרת הופיעה רק אחרי 3 שניות. הסיבה: היא הוצגה רק אחרי ששתי בדיקות רצופות הסכימו, ובטלפון שלך כל בדיקה לוקחת כשנייה.
- **מה תוקן:** המסגרת מופיעה כבר מהבדיקה הראשונה.
- **מה לא השתנה:** קפיצה פתאומית למקום אחר עדיין צריכה שתי בדיקות שמסכימות.

## מדידה
**כריכה סינתטית**, כמו בבדיקת המכשיר:

| | עור | אותיות זהב |
| --- | ---: | ---: |

| "צבע קסם" עד 1.2.4 | 255 (לבן) | 255 |
| "צבע קסם" ב־1.2.5 | 30 | 240 |

**עמוד הספר מהתמונה המקורית ששלחת:** הפלט זהה לגמרי ל־1.2.4.

הפרטים המלאים נמצאים ב־`docs/FILTERS_1.2.5_HE.md`.

## בדיקות
- **בדיקת יחידה:** המסגרת הראשונה מוצגת מיד, וקפיצה בודדת לא מתקבלת.
- **אמולטור, בדיקה חדשה:** כריכה סגולה עם אותיות זהב. "צבע קסם" ו־"Magic Pro" צריכים להשאיר אותה כהה וסגולה.
- **אמולטור, הבדיקות הקודמות:** כולן נשארות.
- **מה צריך לבדוק בטלפון:**
  - לצלם שוב את אותה כריכה עם "צבע קסם";
  - כמה זמן לוקח עד שהמסגרת מופיעה.
