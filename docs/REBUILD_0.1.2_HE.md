# DocScan Native 0.1.2 — פרופורציות, פלט וארגון

ענף `rebuild/camscanner-reference`. המשך לבנייה העצמאית, ללא קוד מהיישום הישן או מענפי העיצוב.

## שינויי הגאומטריה
היישור הקודם בחר רוחב וגובה לפי אורכי הצלעות בצילום. אורכים אלה מתקצרים כשמצלמים מהצד, ולכן אינם יחס העמוד הפיזי. נוסף אומדן מטרי מההומוגרפיה, בהנחת פיקסלים ריבועיים ומרכז אופטי במרכז התמונה. אורך מוקד שקול ל־35 מ״מ נקרא מ־EXIF כשהוא זמין; אחרת נעשה אומדן מהזוויות או אומדן מוקד שמרני במצב שאינו ניתן לכיול חד־משמעי מתמונה אחת.

אין הבטחת יחס מדויק לכל צילום. בחיתוך אפשר לבחור יחס אוטומטי, יחס הצילום, A4, ריבוע או לכוון את הפרופורציות ידנית. ״צילום מלא״ מחזיר את כל המקור ללא חיתוך. יחס התצוגה במסמך נקבע לפי התמונה המעובדת, במקום לפי ממדי המקור לפני חיתוך. התצוגה, JPEG וה־PDF משתמשים באותו מסלול עיבוד.

## פלט התמונות
- במסמך: ״שמירה → שמירת תמונות לגלריה״ מעבדת את כל העמודים לפי הסדר ושומרת כל אחד כ־JPEG נפרד באלבום DocScan.
- בעורך: תפריט ההורדה מציע שמירת הסריקה לגלריה, שמירת הסריקה כ־JPEG, או שמירת המקור. הסריקה משתמשת במתכון הנוכחי בעורך, כולל שינויים שטרם נשמרו למסמך.
- תמונות מעובדות נוצרות מהמקור המלא, בקידוד JPEG באיכות 100. הקידוד עדיין מאבד מידע; רק שמירת המקור מעתיקה את הבתים ללא שינוי.
- Android 10 ומעלה: MediaStore עם רשומות pending בזמן השמירה, ללא הרשאת גישה לכל הגלריה. Android 8–9: הרשאת אחסון מתבקשת רק בלחיצה על שמירה לגלריה.
- כשל רגיל או ביטול בזמן פעולת גלריה מנקים את הרשומות שנוצרו. אין כאן הבטחה לעסקה אטומית מול MediaStore בזמן כיבוי חשמל או סיום תהליך.

## כריכות וחפצים
נוספו מסלולי גבול לכריכות כהות ולגבולות בין צבעים בעלי בהירות דומה, גם בניתוח המצלמה וגם בזיהוי אחרי צילום. לזיהוי פרספקטיבה עדיין נדרשות ארבע פינות ברורות של עצם מלבני; אין הבטחה לזהות כל חפץ. ״זיהוי גבולות״ במצלמה ניתן לכיבוי לצילום מלא, ובמצב זה לא נכפה חיתוך דף ולא מופעל צילום אוטומטי לפי דף.

## בחירה וסל מחזור
לחיצה ממושכת או כפתור הבחירה מאפשרים בחירה יחידה ומרובה ובחירת הכול. מסמכים מועברים לסל מחזור וניתנים לשחזור. אין מחיקה פיזית של מקורות או עריכות, ואין ריקון אוטומטי. Room עובר מסכמה 1 ל־2 במיגרציה שמוסיפה שדה nullable בלבד. שם מסד הנתונים נשאר זהה. אין שינוי בנתוני התקנות DocScan הישנות.

## עיצוב ומנוע
המשתמש ביקש חמש הדמיות ובחירת כיוון לפני שינוי הנראות. שינויי צבעים וניווט הושהו; בקרות חדשות נוספו רק לצורך הפעולות לעיל. ההדמיות אינן צילומים מהאפליקציה ואינן רשימת יכולות שכבר הושלמו.

רק מסנן CamScanner בפרופיל Native מפעיל את MagicEnhancer המקורי. שאר המסננים והגאומטריה הם מימוש עצמאי חדש. אין הצגה של OCR, Word/Excel, הדפסה, יישור קימורי ספר, תיקיות או סנכרון כיכולות שהושלמו. בדיקות Frida ומיפוי הקוד מתועדים בנפרד ב־[דוח JNI](JNI_ENGINE_RESEARCH_HE.md).

## אימות
נוספו בדיקות מטריות לצילום אלכסוני, צילום חזיתי, סיבוב ויחס ידני. בדיקות Android מוסיפות כריכה כהה/צבעונית, התאמה בין גלריה ל־PDF ברזולוציה מלאה, ייצוא מתכון שטרם נשמר, תפריטי שמירה, בחירה ושחזור, ומיגרציית בסיס הנתונים תוך בדיקת hash של המקור.

הבנייה הרגילה וה־Native השלימו מבחני יחידה (9), Lint ובניית APK בסביבת המחקר. [ריצת GitHub Actions](https://github.com/4pdara/DocScan/actions/runs/42124139576) עברה בבנייה ובאמולטורים API 29 באנגלית ו־API 35 בעברית. API 28 נכשל בגישה לאמולטור לאחר החלפת גרסתו, ולכן הריצה הכוללת אינה ירוקה. בדיקות המכשיר הן של הפרופיל הרגיל בלבד.

אין עדיין תוצאה מדודה של גרסה זו בטלפון פיזי או הוכחת שוויון איכות ל־CamScanner. צילומי המשתמש מ־0.1.1 שימשו דיווחי תקלה; אינם בדיקת 0.1.2. [עדכון המסננים ב־0.1.3](FILTER_CATALOG_HE.md) נפרד מממצאי גרסה זו.
