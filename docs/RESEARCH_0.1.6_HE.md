## כלי התצפית במקור

נוספו `research/observe_lifecycle.js` ו־`research/observe_original_startup.py`: הפרדת הפעלה רגילה מתצפית lifecycle, החזקת session/script, תיעוד exit/signal ומודולים, וחיבור Java ו־ARM64. התצפית לא משנה תוצאות רישוי או ערכי חזרה ואינה שולחת סריקות לשירותים.

Frida 17 אינו כולל את גשר Java אוטומטית ב־GumJS גולמי. תוקן חיבור הגשר מחבילת frida-tools 14.11.0 המוצמדת, יחד עם רישום console וטיפול חריגות. client/server הם 17.26.0. [תיעוד הגשרים הרשמי](https://frida.re/docs/bridges/).

נוספו התאוששות ADB מוגבלת ומיקום fixture סינתטי בתיקיית האפליקציה למניעת כשל Scoped Storage. אלו תיקוני כלי בדיקה, לא הוכחת תקינות המסננים המקוריים.

## גבולות והמשך מעשי

ScannerEngine עדיין דורש אתחול SDK מורשה ותקין. הסרת כתב יד, סימני מים ושירותי Pro מסוימים אינם ממומשים כמנוע מקומי מלא. אין שינוי ערכי הצלחה, רישוי, מכסות או גישה לשירותים. עד להשלמת הניסוי במקור אין לסמן את מחקר Frida כ״הושלם״.

נותרו הפעלה מורשית תקינה של חבילת ההפניה, מדידה של כל מסלול שהגיע בפועל לעיבוד, השוואת תמונות ספר אמיתיות, איכות קצוות/טקסט וצריכת זיכרון בטלפון פיזי. המקורות ברזולוציה המקורית נשארים דרישת בסיס בכל ניסוי.
