# DocScan Native 0.1.4 — עיצוב 5, גרסת ניסוי

APK אמיתי להתקנה, בעיצוב המבוסס על ההדמיה שנבחרה. זו גרסת Preview / Pre-release, ולא גרסה סופית או גרסת חנות. השינויים בענף rebuild/camscanner-reference בלבד; main לא שונה ולא הועתק קוד מענפי DocScan הישנים.

## מה כלול

- ספריית מסמכים בהירה בכרטיסים, חיפוש, בחירה יחידה ומרובה, סל ושחזור בלי למחוק מקורות.
- מצלמה שחורה עם גבולות ירוקים, פנס, צילום אוטומטי, בחירת אחת/קבוצה, ייבוא ומונה. צילום יחיד פותח עריכה; קבוצה ממשיכה עד סיום.
- עורך כהה, השוואה למקור, פס מסננים קבוע וכלי חיתוך, יחס ממדים, סיבוב ובהירות/ניגודיות.
- עמודים גדולים בגלילה רציפה, וכפתור עריכה מעל כל תמונה כדי שיהיה נגיש גם בעמוד ארוך.
- תפריט תחתון עם שמירת כל העמודים בגלריה — JPEG נפרד לכל עמוד — PDF, שיתוף, ייבוא, שינוי שם וסידור.
- JPEG בעורך משתמש בעריכה הנוכחית, גם לפני שמירת המתכון. ייצוא ברזולוציית המקור כברירת מחדל; המקור נשמר בנפרד ללא שינוי.

## התקנה ונתונים

שם הקובץ: `DocScan-Native-0.1.4-preview-debug.apk`, ‏64,681,696 בתים. ARM64, ‏Android 8 ומעלה.

מזהה החבילה `com.docscan.rebuild.csnative`, ‏versionCode 4, ‏versionName 0.1.4-native-preview. חתימת Debug זהה ל־Native 0.1.1/0.1.3: SHA256 תעודה `69dce468c27a15728cf501feb9bf76d67263031f5ee34604f78b6be55465e89c`.

מיועדת להתקנה כעדכון לגרסת Native הקודמת. אין צורך להסיר אותה. אין שינוי בסכמת מסד הנתונים או במיקום המקורות בגרסה זו.

SHA256 של APK: `c5e60d85e170f1d38bb46cb3bf3c19ac84b8c477a73dfd37a795ab6c083c004b`. כל 11 הספריות הארוזות זהות לבינארי Native 0.1.3; מנוע העיבוד המוצלח נשאר ללא שינוי.

## בדיקות שהושלמו

- שני הפרופילים נבנו מקומית, עם 9 מבחני יחידה ו־Lint ללא שגיאות. APK ה־Native נבדק מבחינת חבילה, גרסה, חתימה ו־hash.
- [קוד האפליקציה שנבדק](https://github.com/4pdara/DocScan/commit/18367e7a4524dcbe995525d8e21fafd9fccd541a), [ריצת הבדיקות](https://github.com/4pdara/DocScan/actions/runs/42145756242): בנייה ובדיקות API 29 באנגלית ו־API 35 בעברית עברו. בכל אמולטור 16 בדיקות: 15 עברו ו־Native אחת דולגה במפורש בפרופיל הרגיל.
- נבדקו צילום יחיד וקבוצה, עריכה, תצוגה ביחס הטבעי, ייצוא מעובד, מקור ללא שינוי, גלריה/PDF, בחירה/סל/שחזור ומיגרציה.
- API 28 נכשל תחילה בתשתית האמולטור/ADB לפני שהריץ מבחן כלשהו. הריצה החוזרת הושלמה בהצלחה: כל מטריצת build/API 28/API 29/API 35 עברה. שער הפרסום מחייב שוב הצלחה של הריצה המלאה, ואין חריגה למטריצה חלקית.
- אין בדיקה בטלפון אמיתי במסגרת גרסה זו, ואין מדידת שוויון איכות מול CamScanner.

## מסננים ומגבלות מחקר ידועות

חמשת מסלולי Native מ־0.1.3 נשמרו: PAPER, ‏Magic Color, ‏No Shadow, ‏Invert ו־Local Pro. ‏Color/Gray/Ink הם מימוש עצמאי. אין טענה שכל מסנני CamScanner שולבו.

נוצר trace אמיתי של Java ו־JNI ARM64 בתוך DocScan ב־Android 11. PAPER החזיר 0 ו־Magic Color החזיר 2; בדיקות הממדים, האלפא והשינוי בתמונה הסינתטית עברו עבורם. **No Shadow החזיר ‎-1 גם ללא Frida** והפסיק את המבחן. לכן כל חמשת המסלולים עדיין אינם מאומתים כמקשה אחת ב־Android. בעבר היו גם קריסה תחת תצפית ואמולציות פונקציונליות שעברו; ההבחנה מתועדת בדוח המחקר. שגיאה אינה מחליפה מסנן בשקט במסנן אחר.

CamScanner המקורית לא השלימה אתחול בהפצה הרשמית שנבדקה באמולטור Android 11, גם לפני Frida. נעשתה בדיקת השוואה נוספת ב־Android 15. מסנני שרת, OCR, יישור קימורי ספר ופיצול ספר עדיין דורשים פיתוח. כל הממצאים וצעדי הבדיקה הבאים נשמרים ב־[יומן המחקר](RESEARCH_0.1.4_HE.md) וב־[קטלוג המסננים](FILTER_CATALOG_HE.md).
