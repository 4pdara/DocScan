# DocScan Native 0.1.4 — גרסת ניסוי לעיצוב 5

היקף: עיצוב והתנהגות לפי ההדמיה שאושרה, בענף rebuild/camscanner-reference בלבד. אין העתקת קוד מהאפליקציה הישנה. אין שינוי ב־main.

## שינויים

- ספרייה בהירה בכרטיסים, חיפוש ובחירה יחידה/מרובה, העברה לסל ושחזור ללא מחיקת מקורות.
- מצלמה שחורה עם גבולות בירוק, צילום אחת/קבוצה, ייבוא תמונות ומונה עמודים. צילום יחיד פותח עריכה; קבוצה ממשיכה עד סיום.
- עורך כהה, תצוגה ששומרת יחס ממדים, השוואה למקור, פס מסננים קבוע וכלי חיתוך/סיבוב/התאמות.
- מסמך בגלילה רציפה עם תמונות גדולות, PDF ושיתוף; תפריט תחתון כולל שמירת כל העמודים בגלריה כתמונות נפרדות, ייבוא, שינוי שם וסידור.
- שמירת JPEG בעורך משתמשת בעריכה הנוכחית, כולל שינויים שטרם נשמרו. המקור נשמר בנפרד ללא שינוי.

## מנוע ובטיחות נתונים

חמשת המסלולים המקומיים מ־0.1.3 נשמרו: Paper, Magic Color, No Shadow, Invert ו־Local Pro. מסנני Color, Gray ו־Ink הם המימוש העצמאי. אין הכרזה שכל מסנני CamScanner שולבו. אין שינוי בסכמת מסד הנתונים או בתיקיית המקורות.

הגרסה Native שומרת אותו מזהה חבילה ואותה חתימת Debug כמו Native 0.1.1/0.1.3; versionCode עולה ל־4. יש להתקין כעדכון, ללא הסרת ההתקנה. זו גרסת ניסוי ולא גרסת חנות או גרסה סופית.

## אימות

תוצאות בדיקות וקישורי פרסום יתווספו אחרי השלמתן. הוספנו בדיקת צילום יחיד→עריכה ובדיקות ממשק לספרייה, בחירה, גלריה ועורך. בדיקת Frida החדשה מתועדת בנפרד ב־RESEARCH_0.1.4_HE.md.

בדיקת הממשק הראשונה: API 35 בעברית — 16 בדיקות, 15 עברו ו־Native אחת דולגה במפורש. API 29 מצא שני כשלים: כפתור עריכה מתחת לעמוד ארוך, ובדיקת בחירה של תיבות שסומנו כשהן מחוץ לאזור הגלילה הגלוי. כפתור העריכה הועבר לפני התמונה, והבדיקה גוללת לרשת הגלויה ומוודאת שהבחירות נראות. תוצאות הריצה החוזרת יתווספו לפני הפרסום.
