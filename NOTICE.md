# Third-party components

DocScan's development build uses AndroidX (including Compose, CameraX and Room), Kotlin and kotlinx.coroutines. Their primary license is Apache License 2.0. The Gradle Wrapper is generated from the official Gradle 8.13 distribution and retains its upstream notices. The license text is provided in [licenses/Apache-2.0.txt](licenses/Apache-2.0.txt).

Robolectric, JUnit and AndroidX Test are test dependencies. They are not included in the application APK. Native components and transitive dependencies retain their own licenses; a complete distribution inventory must be reviewed before a public store release.

No source code, models, logos or image assets from CamScanner or the researched scanner applications have been copied into this milestone. The current launcher graphic is a temporary development icon, not the selected DocScan logo.

References: [AndroidX](https://android.googlesource.com/platform/frameworks/support/), [Kotlin](https://github.com/JetBrains/kotlin), [kotlinx.coroutines](https://github.com/Kotlin/kotlinx.coroutines), [Gradle](https://github.com/gradle/gradle).
